# Step 5: Generate api-contracts.md

**Goal**: Parse route/handler files, extract HTTP endpoint definitions with request/response structures, write immediately to disk.

**Input**: `repo_path`, `stack`, `framework_type` (from steps 1-2)

**Output**:
- `knowledge-base/02-api-contracts.md` (1-2k tokens)
- Update state.json with outputs_generated and step_completed: 5

---

## Execution

### 1. Locate Route Files by Framework

**Go + GORM**:
- Scan `routes/`, `handlers/`, or `cmd/api/` for HTTP route registrations
- Pattern: `router.GET("/path", handler)` or `router.POST("/path", handler)`

**Go + Pop (Buffalo)**:
- Scan `actions/` directory for handler functions
- Pattern: function names correspond to routes (e.g., `PayoutsCreate` → POST /payouts)

**PHP + Laravel**:
- Read `routes/api.php` or `routes/web.php` for Route definitions
- Pattern: `Route::get('/payouts', 'PayoutController@list')`
- Parse controller files to extract method signatures and request classes

**Angular**:
- Scan `src/app/` for HTTP client service calls
- Pattern: `this.http.get('/api/payouts')`
- Extract from service method definitions

### 2. Parse Endpoint Definitions

For each endpoint found, extract:

**HTTP Method**: GET, POST, PUT, DELETE, PATCH

**Path**: `/api/payouts`, `/api/payouts/:id`, etc.

**Handler/Function**: Name of controller method or handler function

**Request Structure**:
- Read function signature or request class (PHP Form Requests, Go struct)
- Extract input parameters, body fields, query params
- Example: 
  ```
  {
    "payout_id": "string (uuid)",
    "items": [{"item_id": "string", "quantity": "integer", "amount_minor_units": "int64"}],
    "reference": "string (idempotency key)"
  }
  ```

**Response Structure**:
- Read return type or response DTO
- Extract fields and types
- Example:
  ```
  {
    "id": "string (uuid)",
    "amount_minor_units": "int64",
    "status": "enum: pending|completed|failed",
    "created_at": "RFC3339 timestamp"
  }
  ```

**Authentication Type**:
- Check for middleware: Bearer token, API key, Service-to-service, None
- Look for `@auth`, `@middleware('auth')`, or similar annotations

**Known Consumers**:
- Search codebase for references to this endpoint (grep for path string in other repos if available)
- Or read CLAUDE.md API Contracts section if documented
- Example: "orders-service calls this endpoint to finalize payouts"

**Deprecation Status**:
- Check for deprecation markers in code comments (`@deprecated`, `deprecated: true`)
- Default: Not deprecated

### 4. Format Output

Generate 1-2k token version:

```markdown
# API Contracts: orders-service

Generated by `/document-service` on [timestamp]

## Endpoint Listing

### GET /api/payouts
- **Description**: List all payouts with pagination
- **Authentication**: Bearer token (JWT)
- **Query Parameters**:
  - `page` (integer, default: 1)
  - `limit` (integer, default: 20)
  - `status` (string, optional: pending|completed|failed)
- **Response**: 
  ```json
  {
    "data": [
      {
        "id": "uuid",
        "amount_minor_units": "int64",
        "status": "string",
        "created_at": "RFC3339"
      }
    ],
    "pagination": {"page": 1, "limit": 20, "total": 150}
  }
  ```
- **Consumers**: Dashboard (GET to display payouts), Reporting service
- **Status**: Active

### POST /api/payouts
- **Description**: Create new payout
- **Authentication**: Service-to-service (internal Bearer token)
- **Request Body**:
  ```json
  {
    "payout_id": "uuid",
    "items": [{"item_id": "string", "quantity": "integer", "amount_minor_units": "int64"}],
    "reference": "string (idempotency key, required)"
  }
  ```
- **Response**: 
  ```json
  {
    "id": "uuid",
    "status": "pending",
    "amount_minor_units": "int64",
    "created_at": "RFC3339"
  }
  ```
- **Consumers**: Payout Cycle service, reporting-service internal APIs
- **Status**: Active

### PUT /api/payouts/:id/finalize
- **Description**: Finalize payout (mark complete, atomically update journal)
- **Authentication**: Service-to-service
- **Request Body**:
  ```json
  {
    "reference": "string (idempotency key)"
  }
  ```
- **Response**: 
  ```json
  {
    "id": "uuid",
    "status": "completed",
    "amount_minor_units": "int64",
    "finalized_at": "RFC3339"
  }
  ```
- **Error Cases**:
  - 409 Conflict: Already finalized
  - 400 Bad Request: Missing idempotency key
- **Consumers**: Payout Cycle service
- **Status**: Active

[... continue for all endpoints ...]

## Summary
- **Total Endpoints**: 8
- **Authentication Methods**: Bearer token (6), Service-to-service (2)
- **Deprecated Endpoints**: 0
```
